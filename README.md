# PoE1 Leveling Overlay(Korean)

Path of Exile1 한국어 레벨링 노트를 화면 위에 띄워주는 가벼운 AutoHotkey v2 오버레이입니다.

게임 클라이언트 로그를 감시해 지역 이동을 감지하고, 현재 액트의 가이드와 지역별 노트를 자동으로 표시합니다.

## 주요 기능

- 한국어 레벨링 가이드 및 지역별 노트 표시
- `Client.txt` / `KakaoClient.txt` 기반 지역 자동 감지
- 현재 액트에 맞는 노트 자동 전환
- 투명한 Always-on-top 가이드/노트 오버레이
- 수동 액트 선택
- 폰트, 투명도, 토글 단축키 설정
- 주요 Path of Exile 클라이언트 로그 경로 자동 탐색
- **스킬트리 오버레이 (빌드 플래너)**: 스킬트리 이미지 슬라이드쇼를 게임 화면 위에 오버레이로 표시

## 요구 사항

- Windows
- AutoHotkey v2
- AutoHotkey 오버레이가 보이는 Path of Exile 화면 모드

## 사용 방법

1. AutoHotkey v2를 설치합니다.
2. `Main.ahk`를 실행합니다.
3. 로그 파일을 자동으로 찾지 못하면 안내에 따라 Path of Exile 로그 파일을 선택합니다.
4. 가이드 창의 핸들을 드래그해 오버레이 위치를 이동합니다.
5. `F5`를 눌러 오버레이를 숨기거나 다시 표시할 수 있습니다.
6. `Notes/Korean/Act */` 아래의 가이드와 노트 파일을 수정해 내용을 바꿀 수 있습니다.
7. **빌드 플래너 사용법**:
   - `tree/` 폴더에 스킬트리 이미지(`1.png`, `2.png` 등)를 넣습니다.
     - **포맷 및 순서**: `png`, `jpg`, `jpeg` 포맷이 혼합되어 있어도 모두 인식됩니다. 이미지는 파일명 순으로 정렬되므로 `1.png`, `2.jpg`, `3.png`와 같이 순차적인 이름을 지어주시는 것을 권장합니다.
   - `F4`를 눌러 스킬트리 오버레이를 토글(표시/숨김)합니다.
   - `Shift + Space`를 눌러 오버레이 창 위치를 잠금/해제합니다. (잠금 시 마우스 클릭이 창을 통과하여 게임 플레이에 지장을 주지 않습니다.)
   - 오버레이가 표시된 상태에서 `Ctrl + ←` (이전 이미지) 및 `Ctrl + →` (다음 이미지) 단축키로 스킬트리 단계를 변경해가며 볼 수 있습니다.

## 오버레이 위치 이동 및 크기 조절

* **레벨링 가이드 & 노트 창 이동**:
  - 가이드 창 우측 상단에 표시되는 **금색 십자 화살표 아이콘(✥)**을 마우스 좌클릭으로 붙잡고 드래그하여 이동합니다.
  - 가이드 창을 이동하면 왼쪽의 **노트 창**과 **액트 선택 드롭다운 메뉴**가 자석처럼 동기화되어 한꺼번에 따라 움직입니다.
  
* **스킬트리 오버레이 이동 및 크기 조절**:
  - 스킬트리 창이 잠금 해제 상태(기본 단축키 `Shift + Space`를 눌러 활성화)일 때만 마우스 조작이 가능합니다.
  - **이동**: 스킬트리 창 본체의 아무 곳이나 마우스 좌클릭으로 드래그하여 원하는 위치로 이동시킵니다.
  - **크기 조절**: 스킬트리 창 가장자리(모서리)를 마우스로 잡고 끌어당기면 원하는 크기로 크기를 넓히거나 좁힐 수 있습니다.

## 노트 형식

각 액트 폴더에는 다음 파일이 있습니다.

- `guide.txt`: 액트 전체에 표시할 가이드
- `notes.txt`: 지역별로 표시할 노트

지역별 노트는 `zone:` 마커로 구분합니다.

```text
zone:지역 이름
이 지역에 표시할 노트입니다.
```

## 설정

설정은 `config.ini`에 저장됩니다.

시스템 트레이 아이콘의 `프로그램 설정` 메뉴에서 폰트, 글자 크기, 투명도, 오버레이 토글 단축키 및 빌드 플래너 관련 설정(투명도, 토글/잠금/이동 단축키)을 변경할 수 있습니다.

가이드 창 위치는 `guideX`, `guideY`로 저장됩니다. 노트 창은 가이드 창의 왼쪽에 자동으로 붙습니다.
스킬트리 창 위치 및 잠금 여부는 `treeX`, `treeY`, `treeW`, `treeH`, `TreeLocked`로 저장됩니다.

기본 가이드 오버레이 토글 단축키는 `F5`이며, 설정 창이나 `config.ini`의 `[Hotkey] Toggle` 값으로 변경할 수 있습니다.

> [!IMPORTANT]
> **단축키 변경 주의사항 (스페이스바 및 특수 키)**
> Windows 표준 단축키 입력 상자(Common Control)의 한계로 인해, `Shift + Space`와 같이 **스페이스바(`Space`)가 포함된 단축키는 프로그램 설정 창의 단축키 상자에서 직접 입력 및 캡처가 되지 않습니다.**
> 만약 해당 단축키를 스페이스바 조합으로 사용 및 수정하고 싶으시다면, [config.ini] 파일을 텍스트 에디터로 열어서 직접 수정해 주세요.
> - **단축키 기호 표기법**: Shift는 `+`, Ctrl은 `^`, Alt는 `!` 기호를 사용합니다. (예: `ToggleTreeLock=+Space` 등으로 기입)
